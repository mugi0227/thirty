# 画面の設計

## タイマーの画面

参考にした物理タイマーの白いケース、横並びの黒い棒、小さな液晶表示を再現しています。
背景は生成りにし、数字は7セグメントを描画して外部フォントを不要にしました。
暗い配色でも液晶部分は同じ色を保ちます。

メイン画面の文章を削除する要望に合わせ、見出し、励ましの言葉、説明文、ブランド名、時間目盛りを除きました。
時間変更は数字のタップと `+1min`、`+10min`、タイマー操作は再生、一時停止、終了のアイコンです。
画面上部には月とⓘのアイコンを置いています。

アイコンにはVoiceOver向けのラベルを付け、主な操作は44pt以上の領域を確保する実装です。
横向きや大きな文字ではスクロールでき、OSの動きを減らす設定を参照します。
VoiceOver、Dynamic Type、iOSの実際のレイアウトは未確認です。

## 3枚の案内

初回に、設定の手順を3枚に分けて表示します。
1枚目は設定アプリ内の移動先、2枚目は任意の生体認証、3枚目は端末上の物理ボタンです。
設定画面の行とスイッチは操作できない図として示し、OSの設定を変更するボタンとしては扱いません。
説明を閉じたあとはⓘで同じ案内を再表示できます。

## 開始後のボタン案内

計測を始めたあと、該当する物理ボタンの側に「×3」を表示します。
アクセスガイドが実行中になったら消し、不要な場合は×で閉じられます。
位置は物理ボタンの正確な座標ではなく、操作場所を示す目安です。
