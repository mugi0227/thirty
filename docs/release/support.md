# Thirty サポート

## よくある質問

**アクセスガイドを開始できません**
設定 → アクセシビリティ → アクセスガイド をオンにしてから、Thirtyの画面でサイドボタン（ホームボタンのある機種はホームボタン）を3回続けて押してください。

**アクセスガイドを終了するには**
同じボタンを3回押し、パスコード（またはFace ID／Touch ID）で認証して「終了」を選びます。iOS 18以前は2回押す場合があります。タイマーが終わっても自動では終了しません。

**終了の音が鳴りません**
アプリを閉じているときは通知で知らせます。設定 → 通知 → Thirty で通知を許可してください。消音モードや集中モードの設定にも従います。

**Thirty+ を別の端末でも使いたい**
同じApple Accountで、設定 → スキン（またはThirty+の画面）→「購入を復元」を押してください。

**画面が暗いまま戻らない**
アプリを一度開いて閉じると、元の明るさに戻ります。戻らない場合はコントロールセンターで明るさを調整してください。
